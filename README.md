# News-AI-Projesi
Database'in doğru çalışması için aşağıdaki adımları uyguladığınızdan emin olun,
1- PostgreSQL bilgisayarınızda kurulu olmalı.
2- "appsettings.json" dosyasındaki "DefaultConnection" kısmını yerel PostgreSQL username ve password'ünüze göre güncelleyin.
3- Visual Studio içinde Package Manager Console'a "Update-Database" yazarak database'i güncelleyin.
(Manuel olarak başlatmak isterseniz terminale "pg_ctl start" yazın.)
